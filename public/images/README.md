# Direktori Gambar Portofolio

Taruh foto profil Anda di sini dengan nama file:
`profile.jpg` (atau ganti path di `src/components/home/Hero.tsx`)

### Spesifikasi Foto Profil:
- **Rasio:** Potret (3:4 atau 4:5 disarankan)
- **Ukuran:** Minimal lebar 800px – 1200px
- **Format:** JPG, PNG, atau WebP
- **Gaya tampilan:** Otomatis difilter menjadi hitam-putih estetis (`grayscale contrast-[1.04]`) sesuai dengan palet monokromatik portofolio Anda.
